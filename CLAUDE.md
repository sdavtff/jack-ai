# Instruções para o Claude neste projeto

- Sempre que fizer qualquer alteração no código ou na documentação, publique no GitHub automaticamente ao terminar, sem esperar pedido: rode os testes (`npm test`), faça o commit no branch `main` e o `git push origin main`.
- Se os testes falharem, corrija antes de publicar. Se não der para corrigir, avise e não publique.
- Mensagens de commit em português, explicando o que mudou.
- Autor dos commits: `sdavtff <sdavtff@users.noreply.github.com>`. Nunca use o e-mail pessoal.
- Nunca envie `.env`, chaves, a pasta `data/`, bancos `.sqlite` nem `dist/` para o GitHub (o repositório é público).
- Depois de publicar, informe o hash do commit e lembre que o site na Discloud (`jackai.discloud.dev`) só muda depois de subir o novo ZIP de deploy.
